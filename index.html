Featured project

Lens⁸¹ Smart Extension

A Chrome Manifest V3 extension that tells you whether a Google Scholar result is a Research Paper or a Review Paper, and turns any highlighted text into a formatted citation, without leaving the page. Everything runs client side, with no server and no hosted database.

View on GitHub Watch demo
  • Research and Review badges with an ensemble of up to 5 AI models (OpenRouter, Google Gemini, xAI Grok)
  • Local Collections with export to CSV, XLSX, JSON, BibTeX, Markdown and CSL
  • Citation Finder that searches Crossref, Semantic Scholar and OpenAlex in parallel
  • Offline citation formatting with citeproc-js, plus a passcode gate on settings
  • Six versions shipped, built with a team of four
Scholar page→Content script→Service worker→APIs and storage
